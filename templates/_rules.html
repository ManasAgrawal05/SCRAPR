Players

  • Host a game and share the code with friends.
  • {{ rules.min_players }}–{{ rules.max_players }} players can join. The host starts the game once everyone is in.
  • Set your username and picture from the profile button. During a game, the grid shows the leaderboard.

Rounds

  • A game is {{ rules.rounds }} rounds.
  • Each round asks one obscure question that takes several lookups, so no single search gives the answer.
  • The highest total after the last round wins. Equal totals are a draw.

Search rule

  • You can’t search with any word from the question.
  • Small words like “the” and “of” are fine, and plurals count as the same word.

Answers

  • Find the answer with SCRAPR’s search and type it into the answer box.
  • Capital letters, accents and “the” don’t matter. Wrong guesses are unlimited but cost points.
  • Everything stays inside SCRAPR: result links open in the in-app viewer.

Scoring

  • A correct answer starts at {{ rules.base }} points.
  • −{{ rules.per_sec }} per second (up to −{{ rules.max_time }}).
  • −{{ rules.per_click }} per link you click (up to −{{ rules.max_click }}).
  • −{{ rules.per_wrong }} per wrong guess (up to −{{ rules.max_wrong }}).
  • A correct answer is always worth at least {{ rules.floor }}. No correct answer scores 0.

Timers

  • When one player gets it right, everyone else has {{ rules.grace }} seconds to finish.
  • A round also ends after {{ rules.limit_min }} minutes if nobody solves it.
  • There are {{ rules.intermission }} seconds between rounds.
