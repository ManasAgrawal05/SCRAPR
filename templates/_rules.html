The game

  • Host a game and share the code. {{ rules.min_players }}–{{ rules.max_players }} players can join, and the host starts it.
  • A game is {{ rules.rounds }} rounds unless the host picks another number ({{ rules.round_text }}). Each round asks one question. The highest total after the last round wins, and equal totals are a draw.
  • The host picks the settings from the grid menu in the lobby: the number of rounds, the timer length, and the mode’s own options. For the quiz that’s easy questions (one lookup) or difficult ones (several lookups chained together, so no single search gives the answer), and whether the search rule below is on.

Answering

  • Find the answer with SCRAPR’s search and type it into the answer box. Capital letters, accents and “the” don’t matter.
  • Everything stays inside SCRAPR: result links open in the in-app viewer.

Search rule (when switched on)

  • A search can use at most 2 of the question’s key words, and never two of them side by side in the order the question has them. So “scotland animal” is fine, but “national animal” and “scottish national animal” aren’t.
  • Variants count as the same key word (Scotland and Scottish), as do plurals. Other words are unlimited.

Scoring

  • A correct answer starts at {{ rules.base }} points.
  • −{{ rules.per_sec }} per second (up to −{{ rules.max_time }}).
  • −{{ rules.per_click }} per link you click (up to −{{ rules.max_click }}).
  • −{{ rules.per_wrong }} per wrong guess (up to −{{ rules.max_wrong }}).
  • A correct answer is always worth at least {{ rules.floor }}. No correct answer scores 0.

Timers

  • When one player finishes, a countdown starts for everyone else. The host sets its length ({{ rules.timer_text }}); the default is {{ rules.grace }} seconds.
  • A round also ends after {{ rules.limit_min }} minutes if nobody solves it. There are {{ rules.intermission }} seconds between rounds.

Shopping mode

  • You’re given an item to find. Search, click one listing to select it, then press Submit selection. The listing has to mention the item in its title, description or store name. No search restrictions here. The host can switch the star-rating points and the price points on or off.
  • A matching listing starts at {{ rules.shop_base }} points, plus up to {{ rules.shop_rating }} for its star rating (3 stars is 0, 5 stars is the full amount, no rating is 0), up to {{ rules.shop_cost }} for a low price (measured against a normal price range for that item), and up to {{ rules.shop_speed }} for speed (fading over {{ rules.shop_window // 60 }} minutes).
  • −{{ rules.shop_wrong }} for each submission that doesn’t match the item. Rounds, timers and the leaderboard work as above.
